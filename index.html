Guia de Conexão

Conexão Inicial:

  1. Procure a rede WiFi do dispositivo (começa com "EcoFlux-Setup")
  2. Se não aparecer, segure o botão BOOT por 5 segundos
  3. Conecte a essa rede WiFi
  4. Acesse http://192.168.4.1
  5. Configure o WiFi do roteador no dispositivo

Via Celular (Hotspot):

  1. Vá às Configurações Avançadas do Roteador
  2. Procure por tipo de endereço MAC
  3. Mude de MAC Aleatório para MAC do telefone
  4. Altere a Banda WiFi de 5GHz para 2.4GHz
  5. Conecte o dispositivo normalmente
🔒 Privacidade: Senha e WiFi ficam apenas no navegador.
