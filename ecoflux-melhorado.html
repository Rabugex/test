Guia de Conexão

Conexão Inicial:

  1. Procure a rede WiFi do dispositivo (começa com "EcoFlux-Setup")
  2. Se não aparecer, segure o botão BOOT do dispositivo por 5 segundos
  3. Conecte a essa rede WiFi
  4. Abra um navegador e acesse http://192.168.4.1
  5. Configure o WiFi do seu roteador nas configurações do dispositivo

Via Celular (Hotspot):

  1. Vá às Configurações Avançadas do Roteador
  2. Procure por tipo de endereço MAC
  3. Mude de MAC Aleatório para usar o MAC do seu telefone
  4. Altere a Banda WiFi de 5GHz para 2.4GHz (melhor estabilidade)
  5. Conecte o dispositivo normalmente à rede
🔒 Privacidade: Sua senha de usuário e dados de WiFi ficam apenas no seu navegador. Nunca são enviados para servidores externos.
